═════════════════════════════════════════════════════════════════════════════════
✅ PASO 1: SUBIR A GITHUB (5 minutos)
═════════════════════════════════════════════════════════════════════════════════

1. Crea un nuevo repo en GitHub.com llamado "trego"
   (o github.com/TU_USER/trego)

2. En terminal (en la carpeta de Trego):
   
   git init
   git add .
   git commit -m "Initial commit: Trego sistema de liquidaciones"
   git remote add origin https://github.com/TU_USER/trego.git
   git branch -M main
   git push -u origin main

   (Reemplaza TU_USER por tu usuario de GitHub)

3. ✓ Código está en GitHub

═════════════════════════════════════════════════════════════════════════════════
✅ PASO 2: CONECTAR A RAILWAY (3 minutos)
═════════════════════════════════════════════════════════════════════════════════

1. Ve a https://railway.app y crea cuenta (o login)

2. Click "New Project" → "Deploy from GitHub"

3. Conecta tu cuenta GitHub

4. Selecciona repo "trego"

5. Click "Deploy"
   (Railway automáticamente detecta package.json y Procfile)

6. Espera 2-3 minutos a que termine el build

❓ ¿ALGO NO FUNCIONA?
═════════════════════════════════════════════════════════════════════════════════

En Railway Dashboard:
  1. Ve a tu proyecto
  2. Pestaña "Deployments"
  3. Click en último deployment
  4. Mira "Logs"
  5. Busca el error

Errores comunes:
  - "Cannot find module" → Falta npm install
  - "Cannot GET /api" → Backend no arrancó
  - "Monday API error" → API Key inválida
